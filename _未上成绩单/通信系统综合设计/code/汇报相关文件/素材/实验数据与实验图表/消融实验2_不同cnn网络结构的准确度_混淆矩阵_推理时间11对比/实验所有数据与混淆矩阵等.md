## 部署建议：云端服务器

### 结论：推荐 MTx_Net

项目实际部署到 **云端服务器**，这类环境通常：

| 因素 | 云端服务器特点 | 对 MTx_Net 的评价 |
|------|--------------|------------------|
| **CPU为主** | 云端 GPU 成本高，多数推理节点为纯 CPU | ✅ CPU 推理 **4.62ms**，三者中最快 |
| **并发需求** | 单节点处理多路请求，低延迟关键 | ✅ 4.62ms/张，单核可支撑 ~216 QPS |
| **成本敏感** | 按资源付费，参数量越少成本越低 | ✅ 仅 **0.29M** 参数，内存占用极小 |
| **冷启动** | 模型加载速度影响弹性伸缩 | ✅ 模型文件仅 **1.2MB**，秒级加载 |
| **精度要求** | 可接受 <5% 精度损失换取成本优势 | ⚠️ 95.34% vs 99.78%（降 4.44%） |

**具体分析：**

- **CPU 性能**：MTx_Net CPU 4.62ms，分别是 MobileNetV2（14.08ms）的 **3 倍快**、ResNet（17.28ms）的 **3.7 倍快**
- **GPU 性价比**：MobileNetV2 在 GPU 上最快（3.79ms），但云 GPU 实例价格通常是 CPU 实例的 **5-10 倍**，部署 MTx_Net 用 CPU 更经济
- **模型加载**：1.2MB 的模型文件可缓存于内存，无磁盘 I/O 瓶颈
- **扩展性**：0.29M 参数使得单台服务器可同时加载多个肉类品种模型

**如果未来精度需求提升**，可在当前 MTx_Net pipeline 中引入知识蒸馏，以 MobileNetV2 为教师模型提升 MTx_Net 精度，而推理成本不变。
