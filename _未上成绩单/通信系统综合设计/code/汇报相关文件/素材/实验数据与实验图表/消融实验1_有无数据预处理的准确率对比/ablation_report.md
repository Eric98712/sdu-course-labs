# 数据预处理消融实验报告

## 1. 实验目的

评估不同的数据增强策略对肉类新鲜度分类模型的影响，重点关注 **生鲜灯光照** 场景下的鲁棒性。

## 2. 实验设计

### 2.1 训练策略

固定架构为 **MobileNetV2**，训练时不使用知识蒸馏和 ImageNet 预训练，以隔离数据增强策略的纯粹影响。

| 组别 | 数据增强 | 训练集 | 说明 |
|------|---------|--------|------|
| **A** | 无（仅 Resize + Normalize） | 1815张原图 | 基线 |
| **B** | ColorJitter | 1815张原图 | 颜色抖动增强 |
| **C** | 生鲜灯光照模拟 | 1815原图 + 1815生鲜灯增强 = 3630张 | 各图随机 20%-80% 功率 |
| **D** | ColorJitter + 生鲜灯 | 3630张（同上） | 两者叠加 |

### 2.2 测试条件

每个模型在 5 个测试场景下评估：

| 测试条件 | 说明 |
|---------|------|
| **normal** | 原始验证集（无任何干扰） |
| **lamp 0%** | 验证集 × 生鲜灯 0% 功率（即原图复制，控制变量） |
| **lamp 20%** | 验证集 × 生鲜灯 20% 功率 |
| **lamp 50%** | 验证集 × 生鲜灯 50% 功率 |
| **lamp 80%** | 验证集 × 生鲜灯 80% 功率 |

### 2.3 生鲜灯仿真原理

生鲜灯效果基于 **白光LED + 红光LED混光** 的物理原理模拟：

- 红光 LED 功率决定红色偏移程度
- 全功率参数：`red_strength=1.4, alpha=1.2, beta=25, gamma=0.9`
- 各功率级别通过 **全参数联动线性插值** 实现：
  - `param(p) = identity + p × (full - identity)`

## 3. 实验结果

### 3.1 核心数据

| 模型 | 正常 | lamp 0% | lamp 20% | lamp 50% | lamp 80% |
|------|:---:|:-------:|:--------:|:--------:|:--------:|
| **A（基线）** | 86.47% | 86.03% | 85.59% | 85.37% | 82.93% |
| **B（ColorJitter）** | 85.59% | 85.59% | 82.71% | 78.94% | 74.50% |
| **C（生鲜灯增强）** | **89.14%** | **89.14%** | **90.91%** | **88.47%** | **89.58%** |
| **D（两者叠加）** | 88.25% | 88.03% | 88.69% | 87.80% | 85.37% |

## 4. 分析

### 4.1 C 组（生鲜灯增强）全面最优

- 在所有 5 个测试条件下准确率均为最高
- 准确率波动极小（88.47% ~ 90.91%），跨场景最稳定
- 在 lamp 20% 条件下达到最高点 90.91%，甚至超过正常测试集

### 4.2 B 组（ColorJitter）表现最差

- 正常测试集上准确率最低（85.59%）
- 生鲜灯测试下准确率**线性下降**：85.59% → 82.71% → 78.94% → **74.50%**
- 说明 **ColorJitter 引入的颜色变化不仅无益，反而有害**——它让模型对颜色的判断更不稳定

### 4.3 A 组（基线）具有一定鲁棒性

- 正常测试 86.47%，80% 生鲜灯下降至 82.93%，下降约 3.5%
- 基础模型本身对光照变化有一定容忍度

### 4.4 D 组（两者叠加）不如 C 组

- 正常测试 88.25%，80% 生鲜灯下降至 85.37%
- ColorJitter 拖累了生鲜灯增强的效果

### 4.5 包含预训练的结果

当引入 **ImageNet 预训练 + 知识蒸馏** 后，所有模型的准确率均提升至 98% 以上，各组差异被压缩至 <1.5%。这说明：

- 预训练权重已包含对各类光照变化的鲁棒特征
- 在预训练+蒸馏的生产流程下，数据增强策略的边际收益被稀释
- **但在从零训练或无蒸馏的情况下，生鲜灯数据增强带来显著收益**

---

## 5. 结论

### 5.1 最佳实践

| 场景 | 推荐策略 |
|------|---------|
| **从零训练** | **C（生鲜灯增强训练）**，相比基线提升 3-7% |
| **预训练 + 蒸馏** | 各组差别极小，选最简单的 A 即可 |
| **推断时处理生鲜灯** | **无需特殊处理**，C 组模型天然适应 |

### 5.2 关键教训

1. **ColorJitter 在此任务中有害** — 随机颜色变换干扰了肉类颜色判断
2. **针对性的数据增强（生鲜灯）比通用增强（ColorJitter）更有效**
3. **预训练 + 蒸馏是提升鲁棒性的更优路径**，但数据增强在无预训练时至关重要
4. **消融实验的设计需要控制变量** — 初始实验因未统一蒸馏和预训练，所得结论存在偏差
