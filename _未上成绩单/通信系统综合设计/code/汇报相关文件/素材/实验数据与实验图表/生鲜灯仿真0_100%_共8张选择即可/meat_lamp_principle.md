# 生鲜灯仿真原理说明

## 1. 物理原理

### 1.1 生鲜灯的工作方式

真实生鲜灯采用 **白光LED + 红光LED混光** 方案：

- **白光 LED**：提供基础照明，覆盖全光谱
- **红光 LED**：发出 ~620-660nm 红光，使肉色更鲜红
- 通过调节 **红光 LED 的驱动功率** 来改变整体光色

生鲜灯的"美颜"本质是改变照明光谱中红色波段的能量占比，选择性地增强肉类的红色表现。

### 1.2 功率的物理含义

仿真中的"功率百分比"对应红光 LED 的驱动功率：

| 功率 | 红光LED状态 | 视觉效果 |
|------|------------|---------|
| 0% | 关闭 | 仅有白光照明，颜色真实 |
| 50% | 半功率 | 红光与白光混合，颜色偏暖 |
| 100% | 全功率 | 红光充分叠加，红色最明显 |

## 2. 仿真模型

### 2.1 全功率参数定义

基于生鲜灯的光谱特性，定义全功率(100%)时的效果参数：

| 参数 | 值 | 物理含义 |
|------|:---:|---------|
| `red_strength` | 1.4 | 红色通道增益倍数 |
| `alpha` | 1.2 | 对比度系数 |
| `beta` | 25 | 亮度增量 |
| `gamma` | 0.9 | Gamma校正值 |

### 2.2 插值公式

采用 **全参数联动线性插值**，将"无效果"到"全效果"平滑过渡：

$$param(p) = identity + p \times (full - identity), \quad p \in [0.0, 1.0]$$

各参数的 identity（无效果）值：

| 参数 | identity (0%功率) | full (100%功率) | 插值结果 (50%) |
|------|:-----------------:|:---------------:|:--------------:|
| `red_strength` | 1.0 | 1.4 | 1.20 |
| `alpha` | 1.0 | 1.2 | 1.10 |
| `beta` | 0 | 25 | 12.5 |
| `gamma` | 1.0 | 0.9 | 0.95 |

### 2.3 图像处理流程

```
输入图像 → 红色通道增强 → 对比度/亮度调整 → Gamma校正 → 输出图像
```

```
B, G, R = split(image)
R' = R × red_strength          # 红色增强
img' = merge(B, G, R')
img' = convertScaleAbs(α, β)   # 对比度+亮度
img' = gamma_correction(γ)     # Gamma校正
```

## 3. 实现架构

### 3.1 核心函数

| 函数 | 职责 |
|------|------|
| `calculate_power_params(power_pct)` | 根据功率计算插值后的所有参数 |
| `simulate_meat_lamp_power(image, power_pct)` | 接收图像和功率，返回处理结果 |

### 3.2 工程应用

在消融实验中，该仿真被用于：

1. **训练集增强**：每张原图随机生成 20%-80% 功率的生鲜灯版本，与原图一起训练
2. **测试集评估**：对验证集生成 0%/20%/50%/80% 的固定功率版本，评估模型在不同生鲜灯强度下的鲁棒性

### 3.3 关键代码

```python
FULL_POWER_MEAT_LAMP = {
    'red_strength': 1.4,
    'alpha': 1.2,
    'beta': 25,
    'gamma': 0.9
}

def calculate_power_params(power_pct):
    identity = {
        'red_strength': 1.0,
        'alpha': 1.0,
        'beta': 0,
        'gamma': 1.0
    }
    params = {}
    for key in FULL_POWER_MEAT_LAMP:
        params[key] = identity[key] + power_pct * (FULL_POWER_MEAT_LAMP[key] - identity[key])
    return params
```

## 4. 实验验证

消融实验结果表明，经过生鲜灯仿真数据增强训练的模型（C组）：

- 正常测试集准确率：**89.14%**
- 80% 生鲜灯测试集准确率：**89.58%**
- 准确率波动仅 ±1.5%，跨场景稳定性最强

相比未增强的基线（A组）在 80% 生鲜灯下 82.93% 的准确率，提升了 **6.65%**。
