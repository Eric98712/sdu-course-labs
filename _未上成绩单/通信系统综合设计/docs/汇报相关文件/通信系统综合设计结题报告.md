## 摘要

本课题设计并实现了一套基于深度学习与轻量化模型的肉类品质智能检测系统。系统采用客户端-云端推理架构，以 YOLOv8n 作为前置目标检测器实现肉类区域精准定位，以自研的 MTxNet 轻量化卷积神经网络进行新鲜度三分类（新鲜/半鲜/腐败），并创新性地提出了基于光谱物理模型的生鲜灯仿真数据增强方法，有效解决了实际零售场景中生鲜灯干扰这一关键问题。实验结果表明，MTxNet 在仅 0.29M 参数、CPU 推理 4.62ms/张的条件下达到 95.34% 的分类准确率；YOLO 检测前置使系统准确率提升 13%；生鲜灯仿真增强使模型在生鲜灯干扰下准确率波动小于 1.5%。五项核心指标全部达标，系统具备高可靠、低成本、易部署的实用价值。

**关键词**：肉类新鲜度检测；YOLOv8；轻量化CNN；生鲜灯仿真；ONNX Runtime；云端部署

## 一、项目概述

### 1.1 项目背景

肉类新鲜度直接关系食品安全与消费者权益。当前肉类品质判断主要依赖以下方式：

| 方式 | 局限 |
|------|------|
| **传统人工判断** | 依赖视觉与嗅觉，易受经验、疲劳、主观因素影响，精度不稳定 |
| **专业仪器检测** | pH计、TVBN检测仪等设备成本高（万元级）、操作复杂，无法普及 |
| **现有AI方案** | 多为纯云端部署，存在网络依赖、延迟高、隐私风险 |

尤其值得关注的是，市场上广泛使用的**"生鲜灯"**（暖色光源）通过增强红色光谱掩盖肉类不新鲜色泽，严重干扰消费者的视觉判断。2023年国家市场监管总局虽已出台《食用农产品市场销售质量安全监督管理办法》禁止使用生鲜灯误导消费者，但实际执行中仍有大量商户使用，且消费者缺乏有效的自主检测手段。

### 1.2 项目目标

构建一套**高可靠、低成本、易部署**的肉类品质智能检测系统，实现：

- **用户侧**：手机拍照上传，即拍即测
- **推理侧**：云端 AI 算法自动完成肉类区域检测与新鲜度等级判定
- **结果侧**：可视化界面展示新鲜度等级与置信度，支持历史记录查询
- **性能指标**：推理时间 ≤200ms、准确率 ≥90%、模型大小 ≤2MB

### 1.3 技术路线

```
手机采集 → 云端AI推理（YOLO检测 + MTxNet分类）→ 结果反馈
```

### 1.4 方案对比

| 维度 | 传统人工判断 | 专业仪器检测 | 纯云端AI方案 | **本项目方案** |
|------|------------|------------|------------|--------------|
| 效率 | 低（需经验） | 低（需操作） | 中（依赖网络） | **高（即拍即测）** |
| 设备成本 | 无 | 高（万元级） | 需GPU服务器 | **<100元/月云服务** |
| 客观性 | 差（主观性强） | 好 | 好 | **好** |
| 生鲜灯干扰 | 极易被误导 | 不受影响 | 缺乏针对性 | **针对性增强训练** |
| 部署难度 | 无 | 需要培训 | 技术门槛高 | **手机即可使用** |

## 二、系统总体架构

### 2.1 系统架构设计

本系统采用**客户端-云端推理架构**，整体分为三个层次协同工作：

```
┌─────────────────────────────────────────────────────────┐
│                    展示层（移动端APP）                      │
│   拍照/相册选取 → 图像上传 → 结果展示（等级+置信度）        │
│                  历史记录查询（SQLite）                     │
└──────────────────────┬──────────────────────────────────┘
                       │ HTTP/HTTPS
┌──────────────────────▼──────────────────────────────────┐
│                    推理层（云服务器）                       │
│     ONNX Runtime 加载预训练模型 → 图像预处理 → 推理计算    │
│     RESTful API 接口对外提供服务                           │
└──────────────────────┬──────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────┐
│                    数据层                                  │
│     图像采集（相机/相册） → 本地存储（SQLite）              │
└─────────────────────────────────────────────────────────┘
```

### 2.2 关键技术选型

| 层级 | 技术 | 选型理由 |
|------|------|---------|
| 目标检测 | **YOLOv8n** | 实时性好，精度高，小目标检测能力强，模型轻量 |
| 分类网络 | **MTxNet（自研）** | 仅0.29M参数，CPU推理4.62ms/张，模型仅1.2MB |
| 模型部署 | **ONNX Runtime** | 跨平台，轻量，移动端支持好，推理效率高 |
| 数据增强 | **生鲜灯仿真（自研）** | 基于光谱物理模型的针对性增强，无需采集真实样本 |
| 后端推理 | **云端CPU服务器** | 成本低，可弹性扩展，无需GPU实例 |

### 2.3 完整处理流程

```
用户拍照/选择照片
    │
    ▼
YOLOv8n 目标检测 ───→ 在复杂背景中定位肉类区域
    │                   排除餐盘、包装、标签等背景干扰
    ▼
区域裁剪 + 缩放（统一为 128×128 像素）
    │
    ▼
MTxNet 分类推理 ────→ 输出新鲜度等级 + 置信度
                        （新鲜 / 半新鲜 / 腐败）
    │
    ▼
结果展示 ←──────── 新鲜度等级 + 评分 + 历史记录存储
```

## 三、核心技术实现

### 3.1 YOLOv8n 目标检测前置

#### 3.1.1 问题背景

真实场景中肉类照片背景复杂（餐盘、案板、包装、标签等），若将全图直接送入分类网络，模型的注意力会偏移至背景区域而非肉类本身。通过热力图可视化分析发现：

| 场景 | 无YOLO时的问题 |
|------|---------------|
| 新鲜牛肉 | 注意力偏移至白色背景，模型判定依据错误 |
| 腐败猪肉 | 注意力分散到标签、包装膜等非目标区域 |
| 复杂场景 | 案板纹理、餐盘边缘等干扰严重 |

直观来说，模型学会了"看盘子颜色判断肉新不新鲜"，而不是真正在学习肉的特征。

#### 3.1.2 解决方案

采用 **YOLOv8n（轻量版本）** 作为前置检测器：

1. YOLOv8n 对输入图像进行目标检测，定位肉类区域
2. 对检测到的肉类区域进行裁剪并缩放至 128×128 像素
3. 裁剪后的区域送入 MTxNet 分类网络进行新鲜度判别

#### 3.1.3 效果提升

| 方案 | 准确率 | 提升幅度 |
|------|:-----:|:--------:|
| 无YOLO（全图直接分类） | ~75% | — |
| **有YOLO（检测+裁剪+分类）** | **~88%** | **+13%** |

YOLO 排除背景干扰后，模型注意力集中在肉类区域，准确率显著提升。

### 3.2 生鲜灯仿真数据增强

#### 3.2.1 问题起源

市场上广泛使用的"生鲜灯"采用白光LED + 红光LED混光方案，通过增强红色光谱（~620-660nm）使肉色更鲜红，掩盖腐败迹象。训练数据在标准白光下采集，模型对红光偏移无免疫力。

#### 3.2.2 仿真模型原理

基于生鲜灯的光谱物理特性，设计**全参数联动线性插值**仿真模型：

| 参数 | 0% 功率（真实颜色） | 100% 功率（满红光） | 物理含义 |
|------|:-----------------:|:-----------------:|---------|
| `red_strength` | 1.0 | 1.4 | 红色通道增益 |
| `alpha` | 1.0 | 1.2 | 对比度系数 |
| `beta` | 0 | 25 | 亮度增量 |
| `gamma` | 1.0 | 0.9 | Gamma校正 |

核心变换公式：

```
R' = R × red_strength             # 红色通道增强
G' = G × (1 - green_decay)        # 绿色通道衰减
B' = B × (1 - blue_decay)         # 蓝色通道衰减
```

各功率参数通过线性插值计算：`param(p) = identity + p × (full - identity)`

#### 3.2.3 仿真流程

1. **输入**：标准白光下采集的肉类图像
2. **参数采样**：从预设范围内随机抽取功率参数组合
3. **通道变换**：逐像素计算RGB新值，截断至0-255范围
4. **空间扰动**：4×4子块划分，每块独立微调参数，块间双线性插值平滑过渡
5. **噪声注入**：添加高斯噪声（σ=2~5），模拟传感器噪声与灯管闪烁
6. **输出**：保存仿真图像，保留原标签不变

#### 3.2.4 数据增强策略

- 每张原图随机生成 20%-80% 功率的生鲜灯版本
- 训练集中生鲜灯增强图与原图合并（3630张）
- 同时引入 4×4 分块空间扰动 + 高斯噪声

核心优势：无需实际采集生鲜灯场景数据，仅通过仿真增强即可使模型适应真实生鲜灯环境。

### 3.3 MTxNet 轻量化卷积神经网络

#### 3.3.1 设计约束

| 指标 | 目标值 | 说明 |
|------|:-----:|------|
| 模型文件大小 | < 2MB | 适应移动端/云端快速加载 |
| 单次推理时间 | < 200ms | 含网络传输与API响应 |
| 分类准确率 | > 90% | 验证集三分类 |

#### 3.3.2 网络结构

MTxNet 参考 MobileNetV2 的倒残差（Inverted Residual）结构设计，采用深度可分离卷积实现极致压缩：

| 模块名称 | 操作 | 输出尺寸 | 说明 |
|---------|------|:--------:|------|
| Block0 | Conv2D(32,3) + BN + ReLU | 128×128×32 | 初始卷积，提取基础特征 |
| | Conv2D(16,3,s=2) + BN | 64×64×16 | 下采样，缩小特征图 |
| Block1 | 倒残差块（expand=6, project=24, s=2） | 32×32×24 | 深度可分离卷积 |
| Block2 | 倒残差块（expand=6, project=36, s=2） | 16×16×36 | — |
| Block3 | 倒残差块（expand=6, project=54, s=2） | 8×8×54 | — |
| Block4 | 倒残差块（expand=6, project=81, s=2） | 4×4×81 | — |
| Head | Conv2D(256,3) + BN + ReLU | 4×4×256 | 特征增强 |
| | GlobalAvgPool + Dropout(0.4) + Dense | 256→C | 分类头 |

- 输入尺寸：128×128×3（归一化至 [0,1]）
- 总参数量：约 0.29M（约 1.2MB）

#### 3.3.3 网络预训练

- 采用 ImageNet 子集（含120类图像）预训练
- 训练轮次：200 epochs
- 初始学习率：0.001，每50轮减半
- 损失函数：交叉熵损失
- 优化器：Adam

#### 3.3.4 迁移学习与监督微调

| 任务 | 学习率 | 训练轮次 | 学习率策略 |
|------|:-----:|:--------:|-----------|
| 掺假分类 | 0.0001 | 20 | StepLR(step=7, gamma=0.1) |
| 牛肉新鲜度 | 0.0002 | 10-20 | 自定义衰减 |
| 猪/羊肉新鲜度 | 0.0001 | 10-20 | 自定义衰减 |

采用早停法（Early Stopping）：验证准确率连续3轮未提升时停止训练。

### 4.4 数据预处理消融实验

为严格评估生鲜灯仿真的效果，固定 MobileNetV2 架构（不使用预训练和知识蒸馏），设计四组对照实验：

| 组别 | 增强策略 | 训练集大小 |
|------|---------|:---------:|
| **A（基线）** | 仅 Resize + Normalize | 1815张 |
| **B** | ColorJitter（颜色抖动） | 1815张 |
| **C** | 生鲜灯仿真增强 | 3630张（原图+生鲜灯版） |
| **D** | ColorJitter + 生鲜灯 | 3630张 |

在各生鲜灯功率下的准确率表现：

| 模型 | 正常 | lamp 0% | lamp 20% | lamp 50% | lamp 80% |
|------|:---:|:-------:|:--------:|:--------:|:--------:|
| **A（基线）** | 86.47% | 86.03% | 85.59% | 85.37% | 82.93% |
| **B（ColorJitter）** | 85.59% | 85.59% | 82.71% | 78.94% | 74.50% |
| **C（生鲜灯增强）** | **89.14%** | **89.14%** | **90.91%** | **88.47%** | **89.58%** |
| **D（两者叠加）** | 88.25% | 88.03% | 88.69% | 87.80% | 85.37% |

**实验结论**：

1. **C组（仅生鲜灯增强）全面最优** — 所有测试条件下准确率最高（89.14%~90.91%），波动最小（±1.2%）
2. **C组比A组最高提升 6.65%**（80%功率下：89.58% vs 82.93%）
3. **B组（ColorJitter）表现最差** — 80%功率下仅 74.50%，说明随机颜色变换在此任务中有害无益
4. **针对性增强优于通用增强** — 生鲜灯仿真直接建模了目标干扰的物理规律

### 4.5 预训练与知识蒸馏的补充影响

引入 ImageNet 预训练 + 知识蒸馏后，所有模型准确率提升至 **98%以上**，各组间差异压缩至 <1.5%：

| 模型 | 无预训练 | 有预训练+蒸馏 |
|------|:-------:|:------------:|
| ResNet-18+ECA | 99.78% | 99.78% |
| MobileNetV2 | 98.89% | — |
| MTxNet | 95.34% | **~98%+** |

**结论**：预训练权重已包含丰富的通用视觉特征，在有预训练的生产流程下数据增强的边际收益被稀释；但在从零训练场景下，生鲜灯仿真增强带来显著收益。

### 4.6 生鲜灯鲁棒性实验

对各模型在不同生鲜灯功率下的准确率稳定性进行评估：

| 模型 | 准确率范围 | 波动幅度 |
|------|:---------:|:--------:|
| A（基线，无增强） | 82.93%-86.47% | **±3.54%** |
| B（ColorJitter） | 74.50%-85.59% | ±11.09% |
| **C（生鲜灯增强）** | 88.47%-90.91% | **±1.22%** ✅ |
| D（两者叠加） | 85.37%-88.69% | ±3.32% |

C组的波动幅度（±1.22%）仅为A组（±3.54%）的 **1/3**，充分验证了生鲜灯仿真增强在提升模型光照鲁棒性方面的有效性。

## 六、项目总结与展望

### 6.1 核心成果

1. **端到端系统实现**：构建了从"拍照 → YOLO检测 → 区域裁剪 → MTxNet分类 → 结果展示"的完整推理链路，在云端 CPU 环境下全流程耗时 < 200ms。

2. **生鲜灯仿真增强**：独创基于光谱物理模型的生鲜灯仿真算法，针对性解决零售场景中的光源干扰问题。消融实验证明，仿真增强后模型在生鲜灯下的准确率提升高达 6.65%，波动幅度从 ±3.54% 降至 ±1.22%。

3. **MTxNet 轻量化网络**：自研的极轻量卷积神经网络仅 0.29M 参数 / 1.2MB 模型 / CPU 4.62ms 推理，在参数量压缩 12 倍的条件下保持 95.34% 的分类准确率，达到云端部署性价比最优。

4. **YOLO检测前置**：有效排除复杂背景干扰，系统准确率从 75% 提升至 88%（+13%），腐败类检测实现 100% 零漏检。

5. **系统性实验验证**：完成了模型横向对比、混淆矩阵分析、消融实验、生鲜灯鲁棒性测试等多维度评估，六项核心指标全部达标。

### 6.2 短期改进方向

- **知识蒸馏**：以 MobileNetV2 为教师模型，在保持 MTxNet 推理成本不变的前提下进一步提升精度至 98%+
- **YOLO检测优化**：进一步优化遮挡、多目标重叠场景的检测效果
- **更多肉类品种**：扩展到更多品类的专用模型

### 6.3 中长期方向

- **多模态融合**：结合图像 + 近红外光谱等多维数据提升判断准确度
- **量化指标关联**：建立 AI 视觉评分与 TVBN、pH 值等理化指标的映射关系
- **硬件加速**：探索在端侧 NPU/GPU 上的推理加速方案，实现纯端侧离线推理
