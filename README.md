- 🔒 已做**去标识化**处理（姓名、学号、指导教师姓名、联系方式全部移除）
- ⚖️ 第三方版权材料（教师课件、教材电子版、工具与破解器）**仅本地归档**，未进入本仓库

## 仓库结构约定

每门课程目录内部统一分为两组：

| 目录 | 内容 | 是否进入 Git |
| --- | --- | --- |
| `reports/` | 实验报告、论文、课题文档（docx / doc / pdf） | ✅ 是 |
| `code/` | 自己编写的源码、仿真工程、实验数据 | ✅ 是 |
| `slides/` | 自制的汇报 / 答辩 PPT | ✅ 是 |
| `docs/` | 说明、讲义、笔记 | ✅ 是 |
| `courseware/` | 教师课件、教材电子版等**第三方材料** | ❌ 否 |
| `media/` | 演示视频、录音、单文件 > 30 MB 的大文件 | ❌ 否 |
| `archives/` | 提交用的 rar / zip 压缩包 | ❌ 否 |

后三者通过 [`.gitignore`](.gitignore) 排除：它们只服务于本地完整归档，
公开仓库里只保留本人原创内容，避免第三方版权与仓库体积问题。

个别超过 GitHub 单文件 100 MB 硬限制的原创材料（如「电子线路课程设计」的结题 PPT），
改为通过 [Releases](https://github.com/Eric98712/sdu-course-labs/releases) 附件分发。

## 关于去标识化

仓库内所有文档均已移除以下内容：

- 本人及同组同学的**姓名、学号**
- 指导教师**姓名**
- 文档属性（作者、最后修改者）中的个人信息
- 联系类信息（电话、QQ、邮箱）

处理方式因格式而异：

| 格式 | 处理方式 |
| --- | --- |
| `.docx` / `.pptx` / `.xlsx` | 直接改写 OOXML 各部件（正文、页眉页脚、批注、文档属性） |
| `.pdf` | 按字符定位后 redact，覆盖 `search_for` 对中文字体失效的情况 |
| `.doc`（Word 97-2003 二进制） | **等长字节替换**，长度不变以保证 FIB 与 piece table 结构有效 |
| 文本 / 源码 | 字符串替换 |

> 因此报告的封面页上「学生姓名」「学号」等字段会显示为空白，这是预期结果。

## 使用说明

- 这些报告是**个人课程作业存档**，用于记录学习过程与方便日后查阅。
- 实验数据、结论仅代表当时课程要求下的完成情况，**不构成任何研究结论或工程依据**。
- 欢迎参考思路与写法，但请勿直接复制提交 —— 那既违反学术规范，也对自己没有帮助。
- 每个课程目录内的 `README.md` 记录了该课程的学期、属性、学分与内容清单。
