# MathGuide — 考研数学智能辅导助手

> 🚀 **三大独特优势**  
> 🎨 **先画图，再讲解** — 任何函数问题自动生成图像，积分涂色、切线标注，一看就懂  
> 🧠 **苏格拉底式引导** — 不直接给答案，通过追问和变式训练，帮你真正掌握解题思维  
> 📊 **考研专精闭环** — 按数一/二/三考纲，错题本 + 艾宾浩斯复习 + 薄弱点分析，数据驱动提分

---

## 一、项目背景

考研数学涉及高等数学、线性代数、概率论与数理统计三大模块，知识点多、综合性强。当前市面上的辅导方式存在以下痛点：

| 痛点 | 说明 |
|------|------|
| 批改依赖人工 | 解题练习缺乏即时反馈，手写解答无人批改 |
| 错题管理低效 | 纸质错题本整理繁琐，难以统计分析薄弱点 |
| 复习规划盲目 | 缺乏个性化计划，不清楚各阶段该做什么 |
| 答疑成本高 | 一对一辅导价格昂贵，无法随时提问 |
| 公式查询不便 | 遇到不熟悉的公式需要翻书搜索效率低 |

> 据统计，超过 70% 的考研学生在备考中期遇到 "刷题无人批改"、"错题堆积如山" 的问题，最终导致复习效率下降 30% 以上。

---

## 二、系统目标

构建一个 **"学习 → 练习 → 批改 → 记录 → 复习 → 分析 → 再练习"** 的闭环学习系统：

![闭环学习系统](架构图/01_闭环学习.png)

与单次问答工具的本质区别：**每次学习的数据都跨会话持久化，用户下次回来继续从上次进度开始。**

## 四、核心亮点

### 4.1 视觉优先 — 先画图再讲解

与其他数学 AI 不同，MathGuide 不是纯文本对话。当涉及函数、导数、积分、极限、极值时，系统会**先调用 plot_function 生成图像**，然后才开始文字讲解：

| 场景 | 自动生成内容 |
|------|-------------|
| 讲解导数 | 曲线 + 切线图像，展示斜率变化 |
| 讲解定积分 | 曲线 + 积分区域涂色 |
| 讲解极限 | 函数在趋近点附近的局部形态 |
| 讲解极值 | 自动标出极大/极小值点 |

用户不需要自己脑补图形，理解效率大幅提升。

### 4.2 苏格拉底式引导 — 不喂答案，教方法

批改时，如果解答错误，Agent 不会直接给出正确步骤，而是通过追问引导用户自己发现错误：

> "这一步的依据是什么？"  
> "你检查过洛必达的使用条件吗？"  
> "当 x→0 时，分子是否也趋于 0？"

答对后，系统自动生成一道**变式题**（条件微调、结论翻转等），巩固解题思维。

### 4.3 考研专精

| 维度 | 通用 AI | MathGuide |
|------|---------|-----------|
| 知识结构 | 按教材通用 | 按考研数学大纲（数一/二/三） |
| 考纲差异 | 不识别 | 自动标注 "这个知识点数三不考" |
| 出题风格 | 随机 | 真题水平 / 基础 / 提高区分 |
| 解题批改 | 不模拟阅卷 | 10 分制给分 + 扣分点 + 错误归类 |
| 复习系统 | 无 | 艾宾浩斯 8 节点间隔复习 |

### 4.4 闭环学习系统

```
知识点学习 → 变式练习 → 解答批改 → 错题记录 → 间隔复习 → 薄弱点分析 → (返回针对性练习)
```

每个环节的数据跨会话持久化（PostgreSQL），用户下次回来继续从上次的进度开始。

## 六、典型学习会话示例

> 1. 小明上传一道极限计算题的手写解答。  
> 2. 系统自动画出函数在趋近点附近的图像，并批改：第 2 步洛必达使用条件未验证，扣 3 分。  
> 3. AI 追问："当 x→0 时，分子是否也趋于 0？" 小明恍然大悟，修正了解答。  
> 4. 小明答对系统自动生成的变式题后，原题被加入艾宾浩斯复习队列。  
> 5. 3 天后系统提醒复习，小明再次答对，标记为"已掌握"。  
> 6. 每周生成薄弱点雷达图，计划调整为重点练习"极限计算"。
