## 第二部分：路线A — VLM 内化感知（4页）

### Slide 04 — 路线A：核心思想与架构
**核心假设**：将 RF 信号转为频谱图，利用 VLM 视觉编码能力，通过微调将 RF 知识内化到模型参数
**代表工作**：RF-GPT（Khalifa University, arXiv 2026.02）
**架构图**：IQ → STFT → ViT → 线性投影 → Qwen2.5-VL LLM

### Slide 05 — 路线A：RF-GPT 数据管线
**全合成数据**：
- MATLAB 生成 6 种无线技术（5G NR/LTE/UMTS/WLAN/DVB-S2/BT）
- 12,000 个 RF 场景，625,000 条指令-答案对
- 零人工标注（确定性标注 + LLM 指令合成）
- 5 个信息层级：摘要→全局视觉→全局上下文→信号视觉→信号上下文

### Slide 06 — 路线A：RF-GPT 实验结果
**五大基准**：
- WBMC（调制分类）：Easy 82.4% / Medium 74.2% / Hard 47.8%（通用VLM < 7%）
- WBOD（重叠检测）：Easy 91.5% / Medium 87.6% / Hard 71.7%
- WTR（技术识别）：99.64% 联合准确率
- WNUC（用户计数）：70.17%（通用VLM ~23%）
- NRIE（NR信息提取）：SCS 99.1%, SSB 98.2%
- 信号数量识别率：~98%（通用VLM < 5%）

### Slide 07 — 路线A：Seeing Radio（前序工作）+ 路线A小结
**Seeing Radio**（同团队, arXiv 2026.01）：
- 三种可视化方式：时域轨迹/幅度谱图/联合表示
- 57类调制识别：VLM基模~10% → 微调后~90%
- 证明了 VLM 从零学会 RF 感知的可能性

**路线A优势**：端到端简洁、单一模型统一多任务、演示效果好
**路线A劣势**：合成→真实泛化鸿沟、仅与基模对比、黑箱推理、无硬件控制

## 第三部分：路线B — 智能体工具协同（4页）

### Slide 08 — 路线B：核心思想与 WirelessAgent
**核心假设**：LLM 不做 RF 理解，通过工具调用获取专业分析结果，发挥 LLM 长板（推理/编排/对话）
**WirelessAgent**（arXiv 2025.05 + 2026.04）：
- 四模块认知架构：感知 → 记忆 → 规划 → 行动
- 基于 LangGraph 实现
- 网络切片带宽利用率 +44.4%，仅低于最优解 4.3%
- R1 版本：CSI 缺失条件下资源分配，RMSE 降低 67%
- **代码开源**：github.com/jwentong/WirelessAgent_R1

### Slide 09 — 路线B：AICEBERG + 硬件控制
**AICEBERG**（MDPI Smart Cities, 2026.04）：
- 三层架构：LLM推理层 → MCP桥接层 → SCPI硬件控制层
- 双服务器设计：执行 + 安全校验
- 意义：自然语言操控频谱分析仪，第一次打通 LLM + 硬件控制

### Slide 10 — 路线B：产业落地（raNora）+ 混合架构（Multi-LLM DRL）
**raNora**（Aircom 商用产品, 2026.03）：
- 首个商用的电信 Agent AI 平台
- 多 Agent 协作：数据库Agent + 覆盖Agent
- 功能：合规审计、站点规划、覆盖分析

**Multi-LLM Agent DRL**（KTH, 2025-2026）：
- 每个基站/UE 一个 LLM Agent
- LLM 做高层协商，DRL 做低层控制（功率分配/波束赋形）
- 面向 6G 的可扩展方案

### Slide 11 — 路线B小结
**路线B优势**：
- 可调用现成工具（信号处理/小模型/数据库）
- 推理过程可审计、可溯源
- 扩展灵活（新任务 = 新工具）
- 可控制硬件设备、已有商用落地

**路线B劣势**：
- 系统架构复杂、延迟较高
- LLM 幻觉风险（需校验机制）
- 学术发表较难（偏工程）

## 第四部分：综合比较与展望（4页）

### Slide 12 — 多维度对比表
| 维度 | 路线A | 路线B |
|------|-------|-------|
| 核心假设 | 让LLM学会看频谱 | 让LLM调用工具分析频谱 |
| 数据需求 | 高（625K合成对） | 低 |
| 真实信号泛化 | 差 | 好 |
| 硬件控制 | 不支持 | 支持 |
| 可解释性 | 黑箱 | 可审计 |
| 扩展新任务 | 需重新微调 | 加工具即可 |
| 系统复杂度 | 低 | 中高 |
| 产业落地 | 无 | 已有商用 |

### Slide 13 — 案例研究：检测非法干扰
**路线A做法**：
SDR采集 → 频谱图 → VLM直接回答 → 高风险（可能误判，无法溯源）

**路线B做法**：
Agent解析意图 → 调用频谱分析工具 + FCC数据库 → 综合判断 → 每步可审计

### Slide 14 — 核心洞见与结论
**三条结论**：
1. VLM内化感知在学术上有价值，证明了"VLM可以学会看频谱"，但距离工程部署差距较大
2. 智能体协同在产业上更务实，已有商用产品落地
3. 两条路线不是互斥的，未来属于 Agent + VLM + 传统工具的融合架构
